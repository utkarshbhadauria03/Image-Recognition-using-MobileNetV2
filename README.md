# Image Recognition using MobileNetV2

## Overview

This project performs image recognition using TensorFlow's pre-trained MobileNetV2 model.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Pillow
- JupyterLab

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
jupyter lab
```

Open:

```
Image_Recognition_Project.ipynb
```

Run all cells.

## Features

- Image Classification
- Top 5 Predictions
- Pre-trained MobileNetV2
- TensorFlow Deep Learning
